# 로컬 세션 관제판

내 컴퓨터에서 돌린 Claude Code 세션(터미널, 데스크톱 앱의 Code 탭, IDE)을 한 화면에 모아 보는 대시보드예요.

- 지금 **실행 중인 세션**과 그 상태: 작업 중 / 내 차례 / 열려 있음
- 닫힌 세션과 **2주 넘게 안 쓴 세션**(정리 후보)
- 세션마다 제목, 프로젝트, 브랜치, 마지막 요청과 응답, 요청 수, 마지막 활동 시각
- 닫힌 세션은 `재개 명령` 버튼으로 `cd <폴더> && claude --resume <id>` 를 복사

## 실행

```bash
python3 tools/claude-sessions/claude_sessions.py
```

브라우저에서 `http://127.0.0.1:8765` 이 열리고, 5초마다 저절로 갱신돼요. 끌 때는 터미널에서 `Ctrl+C`.

| 옵션 | 설명 |
|---|---|
| `--port 9000` | 다른 포트로 열기 |
| `--no-open` | 브라우저를 자동으로 열지 않기 |
| `--claude-dir <폴더>` | 세션 기록 폴더를 직접 지정 (여러 번 줄 수 있어요). 기본값은 `$CLAUDE_CONFIG_DIR`, 없으면 `~/.claude` |
| `--html out.html` | 지금 상태를 HTML 파일 하나로 저장 (서버 없이 열람) |
| `--json` | 수집한 데이터를 JSON으로 출력 |

Python 3.8 이상이면 되고, 따로 설치할 패키지는 없어요.

## 어디서 읽나요

| 파일 | 쓰는 정보 |
|---|---|
| `~/.claude/projects/*/*.jsonl` | 세션 기록: 제목, 폴더, 브랜치, 요청·응답, 모델, 토큰 |
| `~/.claude/sessions/*.json` | 지금 실행 중인 세션의 PID와 상태. 프로세스가 살아 있는 것만 실행 중으로 봐요 |

상태는 이렇게 정해요.

- **작업 중**: 실행 중이고 상태가 `busy`
- **내 차례**: 실행 중이고 바쁘지 않은데, 마지막이 Claude의 답이거나 도구 승인을 기다리는 것처럼 보임
- **열려 있음**: 실행 중이지만 위 둘에 해당하지 않음
- **닫힘**: 프로세스가 없음

"내 차례"는 기록을 보고 추측한 것이라 실제 화면과 다를 수 있어요.

## 회사에서 써도 되나요

- `127.0.0.1`에만 열려서 같은 네트워크의 다른 사람이 접속할 수 없어요. 다른 사이트가 로컬 데이터를 읽지 못하게 `Host` 헤더도 확인해요.
- 외부로 요청을 보내지 않아요. CDN, 웹폰트, 분석 도구를 하나도 쓰지 않아요.
- `~/.claude` 파일은 읽기만 하고 고치지 않아요.
- `--html`로 저장한 파일에는 세션 제목, 요청, 응답 일부와 폴더 경로가 들어가요. 공유할 때 주의하세요.

## 세션이 안 보이면

데스크톱 앱이 세션 기록을 `~/.claude`가 아닌 다른 곳에 두는 경우가 있을 수 있어요. 터미널에서 찾아보고 `--claude-dir`로 지정하세요.

```bash
find ~ -name "*.jsonl" -path "*projects*" 2>/dev/null | head
```
